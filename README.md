# Vue.js + FastAPI + SQLite 轻量级应用框架

本项目提供了一个基础的入门框架，包含一个 Vue.js 前端和一个 Python FastAPI 后端，使用 SQLite 作为数据库。

## 项目概览

-   **前端：** 一个位于 `frontend/app` 目录下的 Vue.js 应用程序。它包含一个用于管理“项目”的简单界面。
-   **后端：** 一个位于 `backend` 目录下的 FastAPI 应用程序。它提供了针对“项目”的 CRUD API，并使用 SQLite 数据库。

## 快速上手

1.  **克隆本仓库。**
2.  **设置后端：** 请参阅 `backend/README.md` 获取说明。
3.  **设置前端：** 请参阅 `frontend/app/README.md` 获取说明。

您需要同时运行后端和前端的开发服务器才能使用此应用程序。
