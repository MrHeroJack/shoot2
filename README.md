# Vue.js + FastAPI + SQLite Lightweight Application Framework

This project provides a basic starter framework with a Vue.js frontend and a Python FastAPI backend, using SQLite as the database.

## Overview

-   **Frontend:** A Vue.js application located in the `frontend/app` directory. It includes a simple interface to manage "items".
-   **Backend:** A FastAPI application located in the `backend` directory. It provides CRUD APIs for "items" and uses an SQLite database.

## Getting Started

1.  **Clone the repository.**
2.  **Set up the Backend:** See `backend/README.md` for instructions.
3.  **Set up the Frontend:** See `frontend/app/README.md` for instructions.

You will need to have both the backend and frontend development servers running simultaneously to use the application.
